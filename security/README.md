# AIC Security Policy Documents

This directory contains the core security-related policy drafts for Adaptive Intelligence Circle, intended for inclusion in the **AIC-Legal** repository.

## Files

| File | Purpose |
|------|---------|
| [Vulnerability-Disclosure.md](Vulnerability-Disclosure.md) | Coordinated vulnerability disclosure process and safe-harbor statement |
| [Supply-Chain-Security.md](Supply-Chain-Security.md) | Current approach to dependency, build, and third-party code risk |
| [Incident-Response.md](Incident-Response.md) | Lightweight incident response framework aligned with human oversight |

## Status

All documents are **Version 0.1 (Draft)** as of October 2026.  
They are written to be compatible with contemporary international good practice (coordinated disclosure norms, supply-chain awareness, proportionate incident handling) while remaining realistic for a small, pre-Covenant, non-profit-oriented project.

## Design Intent

- Under-claim: describe current intent and capacity, not perfect security.
- Human authority remains central on critical decisions.
- Transparency is preferred once immediate risk is managed.
- Alignment with Ethical-from-kernel and Third Path principles.

These documents should be reviewed and versioned together with the rest of AIC-Legal materials.
